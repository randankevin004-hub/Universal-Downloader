UP AND RUNNING IN A MINUTE

Install Universal Downloader

The installer is small. On first launch, the app checks your PC for yt-dlp. If it cannot find one, you can allow it to download a separate copy from the official yt-dlp GitHub release.

  1. 01
    Download the installer

    Choose Download for Windows above and wait for the .exe file to finish.

  2. 02
    Run the setup file

    Install for your Windows account. The installer does not need administrator access.

  3. 03
    Check your tools

    If yt-dlp is already on your PC, the app uses it. Otherwise, choose Set up to download the app's own copy. Internet access is needed for setup.

i

A note about FFmpeg and Windows

FFmpeg is optional, but some separate audio and video streams need it to combine the files. Without FFmpeg, the app uses a combined format when the site offers one. Windows may show a SmartScreen warning because this installer is not code-signed.

Universal Downloader

Downloads depend on the website and available formats. The app does not bypass DRM or access controls. Only download media you have permission to save.
